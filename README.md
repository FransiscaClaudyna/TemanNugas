# 📚 TemanNugas

**TemanNugas** adalah aplikasi web manajemen tugas dan jadwal kuliah berbasis HTML5, CSS3, dan JavaScript Vanilla yang dirancang untuk membantu mahasiswa mengelola tugas, prioritas, serta pengingat tenggat secara terencana.

---

## 🌟 Fitur Utama

- 🔐 **Login Gate**: Halaman autentikasi awal sebelum masuk ke Dashboard.
- 📊 **Dashboard**: Ringkasan statistik total tugas, tugas yang telah selesai, dan tenggat terdekat.
- 📝 **Daftar Tugas**: Manajemen tugas (Tambah, Hapus, Selesai) serta filter prioritas (*Tinggi*, *Sedang*, *Rendah*).
- 📅 **Jadwal Kuliah**: Informasi jadwal mata kuliah dan ruangan.
- 🔔 **Pengingat**: Notifikasi pengingat tenggat tugas.
- 🌙 **Dark / Light Mode**: Mode tampilan gelap dan terang yang tersimpan otomatis di `localStorage`.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur halaman web multi-page (`login.html`, `index.html`, `tugas.html`, `jadwal.html`, `pengingat.html`).
- **CSS3**: Layout responsif (Flexbox & Grid) serta CSS Variables untuk tema Dark Mode.
- **JavaScript (Vanilla)**: Logika interaktif, manipulasi DOM, dan penyimpanan data via `localStorage`.
- **Git & GitHub**: Version control dan kolaborasi tim.
 
## 🚀 Cara Menjalankan Proyek
1. Buka repository GitHub TemanNugas : https://github.com/FransiscaClaudyna/TemanNugas
2. Klik Code → Download ZIP.
3. Ekstrak file ZIP yang telah diunduh.
4. Buka folder proyek menggunakan browser dengan membuka file login.html, atau gunakan VS Code dengan ekstensi Live Server.
5. Gunakan menu navigasi untuk menjelajahi halaman Dashboard, Daftar Tugas, Jadwal, dan Pengingat.
